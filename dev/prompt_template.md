## Technical Specifications & Architecture

### 1. Provider Contract
Every provider file must attach a provider object to `window` and self-register with `window.LLMRegistry`:

```javascript
window.[ProviderName]Provider = {
  name: "string",             // Display name (e.g. "Gemini", "Perplexity")
  urlMatch: RegExp,           // Regex matching active chat URLs
  isGenerating: () => boolean,// Returns true ONLY while the model is streaming/generating
  getContainer: () => Element,// Returns document.body for fixed overlays
  getThemeColors: () => ({    // Extracts background and brand/accent colors dynamically
    background: "string",     // CSS color / hex string
    text: "string"            // CSS brand/accent color for payload styling
  })
};

if (window.LLMRegistry) {
  window.LLMRegistry.register(window.[ProviderName]Provider);
}

```

### 2. Analysis & Implementation Rules

1. **State Detection (`isGenerating`)**:
* Compare `[IDLE_STATE_HTML]` and `[GENERATING_STATE_HTML]`.
* Identify an element present *only* during generation (e.g., a "Stop Generating" button, active stop icon, or specific `aria-label`/`data-testid`).
* Prioritize stable semantic selectors (e.g., `[data-testid="..."]`, `[aria-label="..."]`, `button[type="..."]`) over autogenerated or hashed CSS class names.


2. **Container Anchor (`getContainer`)**:
* Return `document.body` to preserve layout integrity with fixed-position overlays.


3. **Theme Extraction (`getThemeColors`)**:
* Use `window.getComputedStyle(document.body)` or `window.getComputedStyle(document.documentElement)` to dynamically read CSS variables found in `[CONSOLE_CSS_DUMP]`.
* Identify the variable representing the main canvas/page background.
* Identify the variable representing the primary brand/accent color (not plain white/black body text).
* Always supply a hardcoded fallback string matching the observed values in case variables fail to resolve.


4. **Self-Registration**:
* Always wrap registration in `if (window.LLMRegistry) { window.LLMRegistry.register(...); }`.

## Reference Implementation

### `src/registry.js`

```javascript
window.LLMRegistry = {
  providers: [],
  register: function (provider) {
    this.providers.push(provider);
  },
  getActiveProvider: function () {
    const currentUrl = window.location.href;
    return this.providers.find((provider) => provider.urlMatch.test(currentUrl));
  },
};

```

### `src/providers/claude.js` (Example Reference)

```javascript
window.ClaudeProvider = {
  name: "Claude",
  urlMatch: /claude\.ai/,
  isGenerating: () => {
    return document.querySelector('[data-testid="chat-input-stop"]') !== null;
  },
  getContainer: () => {
    return document.body;
  },
  getThemeColors: () => {
    const styles = window.getComputedStyle(document.body);
    return {
      background: styles.getPropertyValue("--cds-page-bg").trim() || "#151515",
      text: styles.getPropertyValue("--cds-fill-brand").trim() || "#c6613f",
    };
  },
};

if (window.LLMRegistry) {
  window.LLMRegistry.register(window.ClaudeProvider);
}

```

(function dumpTheme() {
  const root = window.getComputedStyle(document.documentElement);
  const body = window.getComputedStyle(document.body);
  const cssVars = {};
  
  for (let sheet of document.styleSheets) {
    try {
      for (let rule of sheet.cssRules) {
        if (rule.style) {
          for (let i = 0; i < rule.style.length; i++) {
            const name = rule.style[i];
            if (name.startsWith('--') && (name.includes('bg') || name.includes('brand') || name.includes('accent') || name.includes('surface') || name.includes('primary') || name.includes('color'))) {
              cssVars[name] = body.getPropertyValue(name).trim() || root.getPropertyValue(name).trim();
            }
          }
        }
      }
    } catch (e) {}
  }
  
  console.log("Computed Body BG:", body.backgroundColor);
  console.log("Computed Body Color:", body.color);
  console.log("Relevant CSS Variables:", JSON.stringify(cssVars, null, 2));
})();
